# Architecture decision records

ADRs document consequential technical choices and their status. Proposed choices remain reviewable and should not be treated as bank approval. Use sequential filenames such as `0001-documentation-first-foundation.md`.

## Index

- [0001: Documentation-first foundation and repository names](0001-documentation-first-foundation.md)
- [0002: Baseline technology and modular architecture](0002-baseline-technology.md)
- [0003: Dynamic application authorization](0003-dynamic-authorization.md)
- [0004: Central Microsoft 365 integration boundary](0004-microsoft-integration-boundary.md)

## Template

```markdown
# NNNN: Decision title

- Status: Proposed | Accepted | Superseded | Rejected
- Date: YYYY-MM-DD

## Context
## Decision
## Alternatives considered
## Consequences
## Revisit when
```
